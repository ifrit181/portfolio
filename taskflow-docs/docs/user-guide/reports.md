# Отчёты

Раздел **Отчёты** позволяет анализировать загрузку команды, соблюдение
сроков и прогресс по проектам. Отчёты помогают принимать решения:
перераспределять задачи, сдвигать сроки, выявлять узкие места.

## <a id="доступные-отчёты">Доступные отчёты</a>

### Загрузка сотрудников

Показывает количество задач по каждому сотруднику и распределение
по приоритетам.

**Что видно:**

- сколько задач у каждого исполнителя;
- сколько из них просрочено;
- распределение по приоритетам;
- среднее время выполнения.

**Как использовать:** выявить перегрузку. Если у сотрудника в три раза
больше задач, чем у остальных, — пора перераспределить.

### Сроки задач

Список задач с дедлайнами и статусом. Просроченные выделяются красным.

**Что видно:**

- задачи с дедлайном на этой неделе;
- просроченные задачи;
- задачи без срока;
- задачи с приближающимся дедлайном (за 2 дня).

**Как использовать:** на ежедневных стендапах. Открыть отчёт — и сразу
видно, где горит.

### Прогресс проектов

Обобщённая статистика по всем проектам: количество выполненных задач,
оставшиеся спринты, ближайшие вехи.

**Что видно:**

- процент завершения по каждому проекту;
- отклонение от плана;
- ближайшие вехи и их статус;
- проекты без активности более 7 дней.

**Как использовать:** для статус-митингов с руководством.

### Динамика по неделям

График выполненных задач по неделям. Показывает тренд: растёт
производительность или падает.

**Что видно:**

- количество закрытых задач за неделю;
- сравнение с предыдущей неделей;
- среднее время цикла (от создания до завершения).

### Проблемные задачи

Список задач, которые долго не двигаются:

- в статусе **В работе** более 14 дней;
- в статусе **На проверке** более 7 дней;
- без исполнителя более 3 дней.

**Как использовать:** для разбора завалов и поиска узких мест в процессе.

## <a id="фильтры-и-периоды">Фильтры и периоды</a>

Все отчёты поддерживают фильтрацию:

| Фильтр | Значения |
| --- | --- |
| Период | Сегодня, неделя, месяц, квартал, произвольный |
| Проект | Один или несколько |
| Команда | По месту работы или отделу |
| Исполнитель | Конкретный сотрудник или группа |
| Приоритет | Низкий, средний, высокий, критический |
| Теги | Один или несколько |

### Пример: задачи по критическому приоритету за месяц

1. Откройте отчёт **Сроки задач**.
2. Период: **Последний месяц**.
3. Приоритет: **Критический**.
4. Нажмите **Применить**.

### Сохранение фильтра

Если фильтр нужен регулярно — сохраните его как **представление**:

1. Настройте фильтры.
2. Нажмите **Сохранить представление**.
3. Укажите название.
4. Представление появится в левом меню раздела.

## <a id="экспорт">Экспорт</a>

1. Откройте нужный отчёт.
2. Нажмите **Экспорт**.
3. Выберите формат:

   | Формат | Когда использовать |
   | --- | --- |
   | Excel (`.xlsx`) | Для дальнейшего анализа |
   | PDF | Для отправки руководству или заказчику |
   | CSV | Для загрузки в BI-систему |

4. Выберите поля для выгрузки.
5. Нажмите **Скачать**.

!!! note "Экспорт больших отчётов"
    Если в отчёте больше 1000 строк, экспорт выполняется в фоне.
    Ссылка на файл придёт на email.

## <a id="автоматические-отчёты">Автоматические отчёты</a>

Можно настроить регулярную отправку отчёта на email.

1. Откройте отчёт.
2. Нажмите **Расписание**.
3. Укажите периодичность: ежедневно, еженедельно, ежемесячно.
4. Добавьте получателей.
5. Нажмите **Сохранить**.

Отчёт будет приходить в выбранном формате в указанное время.

!!! tip "Дашборд для руководителя"
    Вместо пяти отчётов настройте один дашборд. Виджеты обновляются
    автоматически, и не нужно каждый раз открывать раздел.
