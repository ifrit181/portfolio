# Отчёты

Раздел **Отчёты** позволяет анализировать загрузку команды и выполнение
сроков.

## Доступные отчёты

### Загрузка сотрудников

Показывает количество задач по каждому сотруднику и распределение
по приоритетам. Помогает выявить перегрузку.

### Сроки задач

Список задач с дедлайнами и их статусом. Задачи с просроченными сроками
выделяются автоматически.

### Прогресс проектов

Обобщённая статистика по всем проектам: количество выполненных задач,
оставшиеся спринты, ближайшие вехи.

## Экспорт отчётов

1. Откройте нужный отчёт.
2. Нажмите **Экспорт**.
3. Выберите формат: **Excel** или **PDF**.
4. Выберите поля для выгрузки и нажмите **Скачать**.
