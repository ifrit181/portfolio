# Проекты

Проект — контейнер для задач, объединённых общей целью. У проекта есть
участники, сроки и статус.

## <a id="создание-проекта">Создание проекта</a>

1. В разделе **Проекты** нажмите **Создать проект**.
2. Укажите **Название** и **Описание**.
3. Добавьте **Участников** из списка пользователей.
4. Укажите **Дату начала** и **Срок окончания**.
5. Нажмите **Сохранить**.

## <a id="спринты">Спринты</a>

Спринт — фиксированный промежуток времени (обычно 1–2 недели), в течение
которого команда выполняет запланированный объём задач.

Чтобы создать спринт:

1. Откройте проект → вкладка **Спринты**.
2. Нажмите **Создать спринт**.
3. Укажите **Название** и **Период**.
4. Добавьте задачи из бэклога проекта.

## <a id="вехи">Вехи</a>

Веха — ключевое событие в проекте с фиксированной датой. Вехи помогают
отслеживать прогресс по критическим точкам: релиз, запуск, сдача отчёта.

## <a id="статусы-проектов">Статусы проектов</a>

| Статус | Описание |
| --- | --- |
| Активный | Проект в работе |
| На паузе | Работа приостановлена |
| Завершён | Задачи выполнены, проект закрыт |
| Архив | Проект доступен только для чтения |
