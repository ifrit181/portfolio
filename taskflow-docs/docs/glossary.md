# Глоссарий

**Проект**
: Контейнер для задач, объединённых общей целью. У проекта есть участники,
  сроки и статус.

**Спринт**
: Фиксированный промежуток времени (обычно 1–2 недели), в течение которого
  команда выполняет запланированный объём задач.

**Канбан-доска**
: Представление задач в виде колонок по статусам. Карточки перетаскиваются
  между колонками.

**Веха**
: Ключевое событие в проекте с фиксированной датой.

**Тег**
: Метка для категоризации и фильтрации задач.

**Роль**
: Набор прав пользователя в системе. Роли: Сотрудник, Менеджер,
  Администратор.
