# Настройки

Раздел **Администрирование** → **Настройки** доступен только
администраторам.

## Общие настройки

- **Название системы** — отображается в заголовке и уведомлениях.
- **Язык по умолчанию** — язык интерфейса для новых пользователей.
- **Часовой пояс** — используется для сроков и отчётов.

## Настройки уведомлений

### SMTP

Для отправки email-уведомлений укажите параметры SMTP-сервера:

| Поле | Описание |
| --- | --- |
| SMTP-хост | Адрес почтового сервера |
| Порт | Порт (обычно 465 для SSL или 587 для TLS) |
| Логин | Учётная запись отправителя |
| Пароль | Пароль отправителя |

После сохранения нажмите **Отправить тестовое письмо**, чтобы проверить
настройки.

### Типы уведомлений

Включите или отключите уведомления по событиям: новая задача, изменение
статуса, напоминание о сроке, комментарий.
