# Пользователи

Раздел **Администрирование** → **Пользователи** доступен только
администраторам.

## Создание пользователя

1. Нажмите **Создать пользователя**.
2. Укажите **Имя**, **Email** и **Пароль**.
3. Выберите **Роль**:

| Роль | Права |
| --- | --- |
| Сотрудник | Задачи, проекты, комментарии |
| Менеджер | Всё, что доступно сотруднику, плюс отчёты и массовые операции |
| Администратор | Полный доступ, включая управление пользователями и настройками |

4. Нажмите **Сохранить**.

## Роли и права

Роли назначаются вручную администратором. Изменить роль можно в любой
момент — новые права вступают в силу сразу.

## Отключение пользователя

Чтобы ограничить доступ, откройте пользователя и нажмите **Отключить**.
Аккаунт не удаляется, но вход в систему блокируется.
