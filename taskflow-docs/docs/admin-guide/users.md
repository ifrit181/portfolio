# Пользователи

Раздел **Администрирование** → **Пользователи** доступен только
администраторам. Здесь создаются учётные записи, назначаются роли
и управляется доступ к системе.

## <a id="создание-пользователя">Создание пользователя</a>

1. Нажмите **Создать пользователя**.
2. Укажите **Имя**, **Email** и **Пароль**.
3. Выберите **Роль** (см. таблицу ниже).
4. Укажите **Место работы** и **Отдел** — используются в отчётах.
5. Нажмите **Сохранить**.

!!! note "Требования к паролю"
    Минимум 8 символов, хотя бы одна заглавная буква, одна цифра
    и один специальный символ. Пароль можно сгенерировать автоматически
    кнопкой **Сгенерировать**.

## <a id="роли-и-права">Роли и права</a>

| Роль | Задачи | Проекты | Отчёты | Пользователи | Настройки |
| --- | --- | --- | --- | --- | --- |
| Сотрудник | Свои | Просмотр | — | — | — |
| Менеджер | Все | Управление | Да | — | — |
| Администратор | Все | Управление | Да | Управление | Полный доступ |

Роли назначаются вручную администратором. Изменения вступают в силу
сразу, без перелогина.

!!! warning "Принцип минимальных привилегий"
    Назначайте роль **Администратор** только тем, кому действительно нужен
    полный доступ. Для повседневной работы достаточно **Менеджера**.

## <a id="приглашение-по-email">Приглашение по email</a>

Вместо создания пароля вручную можно отправить приглашение:

1. Нажмите **Пригласить пользователя**.
2. Укажите email и роль.
3. Нажмите **Отправить приглашение**.

Пользователь получит письмо со ссылкой. Ссылка действует 7 дней.

## <a id="массовый-импорт">Массовый импорт</a>

Для добавления десятков пользователей используйте CSV-файл.

### Формат файла

```csv
name,email,role,department
Иван Петров,ivan@company.com,employee,Разработка
Мария Сидорова,maria@company.com,manager,Аналитика
```

### Импорт

1. Нажмите **Импорт из CSV**.
2. Загрузите файл.
3. Проверьте предпросмотр — система покажет, сколько строк корректны.
4. Нажмите **Импортировать**.

!!! warning "Проверка перед импортом"
    Если в файле есть ошибки (дубли email, неверные роли), импорт
    остановится. Исправьте файл и загрузите снова.

## <a id="редактирование-профиля">Редактирование профиля</a>

Администратор может изменить у любого пользователя:

- имя и email;
- роль;
- место работы и отдел;
- часовой пояс;
- язык интерфейса.

Пользователь может редактировать эти же поля самостоятельно, кроме роли.

## <a id="сброс-пароля">Сброс пароля</a>

### Пользователь забыл пароль

1. Откройте пользователя.
2. Нажмите **Сбросить пароль**.
3. Система отправит письмо со ссылкой.

### Принудительный сброс

Если пользователь не может получить письмо:

1. Откройте пользователя.
2. Нажмите **Задать новый пароль**.
3. Введите временный пароль.
4. Передайте его пользователю безопасным каналом.
5. Поставьте галочку **Требовать смену при следующем входе**.

## <a id="блокировка-и-отключение">Блокировка и отключение</a>

Два разных действия:

| Действие | Что происходит |
| --- | --- |
| **Заблокировать** | Вход запрещён, сессии завершаются, данные сохраняются |
| **Отключить** | Аккаунт деактивирован, но может быть восстановлен |

### Когда использовать

- **Заблокировать** — при подозрении на взлом или при временном
  отстранении сотрудника.
- **Отключить** — когда сотрудник уволился, но данные могут понадобиться.

## <a id="удаление-пользователя">Удаление пользователя</a>

!!! warning "Удаление необратимо"
    При удалении все задачи пользователя переходят в статус
    **Без исполнителя**, комментарии сохраняются с пометкой
    **Удалённый пользователь**.

Порядок удаления:

1. Откройте пользователя.
2. Нажмите **Удалить**.
3. Выберите, кому передать задачи.
4. Подтвердите действие.

## <a id="аудит-действий">Аудит действий</a>

Все действия с пользователями фиксируются в журнале:

- кто создал, изменил, удалил пользователя;
- когда изменилась роль;
- кто сбросил пароль;
- когда пользователь входил последний раз.

Журнал доступен в разделе **Администрирование → Журнал аудита**.

!!! tip "Регулярный аудит"
    Раз в квартал проверяйте список администраторов и отключайте
    тех, кому больше не нужен полный доступ.
