## <a id="общие-вопросы">Общие вопросы</a>

### Как сбросить пароль?

На странице входа нажмите **Забыли пароль?** и укажите email.
Система отправит ссылку для сброса. Ссылка действует **30 минут**.

Если письмо не приходит — проверьте папку «Спам» и правильность email.
Если email указан неверно — обратитесь к администратору.

### Как изменить email или имя?

Откройте **Профиль → Настройки**. Измените поля и нажмите **Сохранить**.

Email можно изменить только на тот, который ещё не используется
в системе.

### Как переключить язык интерфейса?

**Профиль → Язык**. Доступны русский и английский.

### Как включить тёмную тему?

**Профиль → Тема**. Три режима: светлая, тёмная, системная.

### Можно ли работать с телефона?

Да. TaskFlow поддерживает мобильные браузеры и PWA-приложение.
Установите PWA: откройте сайт в браузере → **Добавить на главный экран**.

## <a id="задачи">Задачи</a>

### Можно ли восстановить удалённую задачу?

Да, в течение **30 дней**. Откройте **Проект → Корзина**, найдите
задачу и нажмите **Восстановить**. Через 30 дней задачи удаляются
безвозвратно.

### Как экспортировать задачи в Excel?

1. Откройте проект.
2. Нажмите **Экспорт → Excel**.
3. Выберите поля для выгрузки.
4. Нажмите **Скачать**.

Если задач больше 1000, экспорт выполняется в фоне — ссылка придёт
на email.

### Как назначить несколько исполнителей на одну задачу?

Откройте задачу → поле **Исполнитель** → выберите несколько человек.
Каждый получит уведомление.

### Как разбить большую задачу на подзадачи?

Два способа:

- **Чек-лист** — если подшаги небольшие и не требуют отдельных
  исполнителей.
- **Дочерние задачи** — если каждый подшаг требует своего исполнителя
  и срока.

### Что означает статус «Заблокирована»?

Задача не может двигаться дальше из-за внешнего препятствия.
Укажите причину в комментарии и свяжите с блокирующей задачей
через **Связи → Блокирует**.

## <a id="проекты-и-спринты">Проекты и спринты</a>

### Чем отличается Канбан от Scrum?

| Тип | Когда использовать |
| --- | --- |
| Канбан | Непрерывный поток задач, без фиксированных итераций |
| Scrum | Работа спринтами с планированием и ретроспективой |
| Список | Простой список без доски и спринтов |

### Как перенести незавершённые задачи в следующий спринт?

При завершении спринта система предложит перенести незакрытые задачи.
Выберите **Перенести в следующий спринт** или **Вернуть в бэклог**.

### Как архивировать проект?

**Настройки проекта → Архивировать**. Проект станет доступен только
для чтения. Восстановить можно из раздела **Проекты → Архив**.

### Можно ли удалить проект?

Да, но это **необратимо**. Перед удалением рекомендуется архивировать
проект. Все задачи, комментарии и вложения исчезнут.

## <a id="отчёты">Отчёты</a>

### Как сохранить фильтр в отчёте?

Настройте фильтры → нажмите **Сохранить представление** → укажите
название. Представление появится в левом меню раздела.

### Почему отчёт показывает не все задачи?

Проверьте фильтры. Возможно, установлен период, проект или исполнитель,
которые исключают часть данных. Нажмите **Сбросить фильтры**.

### Как настроить автоматическую отправку отчёта?

1. Откройте отчёт.
2. Нажмите **Расписание**.
3. Укажите периодичность и получателей.
4. Сохраните.

### Можно ли экспортировать отчёт в CSV?

Да. **Экспорт → CSV**. Формат подходит для загрузки в BI-системы.

## <a id="уведомления">Уведомления</a>

### Не приходят уведомления на email

Проверьте по порядку:

1. **Настройки SMTP** в разделе **Администрирование → Настройки**.
2. Папку «Спам».
3. Что в профиле указан актуальный email.
4. Что уведомления не отключены в **Профиль → Уведомления**.

### Как отключить уведомления по некоторым событиям?

**Профиль → Уведомления**. Снимите галочки с ненужных событий.
Системные уведомления (например, о сбросе пароля) отключить нельзя.

### Что такое еженедельный дайджест?

Письмо с обзором событий за неделю: закрытые задачи, ближайшие вехи,
просроченные дедлайны. Отправляется по понедельникам в 9:00.

## <a id="администрирование">Администрирование</a>

### Как добавить нового пользователя?

**Администрирование → Пользователи → Создать пользователя**.
Укажите имя, email, пароль и роль.

Для массового добавления используйте **Импорт из CSV**.

### Как изменить роль пользователя?

Откройте пользователя → **Роль** → выберите новую. Изменения вступают
в силу сразу, без перелогина.

### Чем отличается блокировка от отключения?

| Действие | Что происходит |
| --- | --- |
| Заблокировать | Вход запрещён, сессии завершаются |
| Отключить | Аккаунт деактивирован, но может быть восстановлен |

### Как передать задачи уволенного сотрудника?

При удалении пользователя система предложит выбрать, кому передать
задачи. Все задачи перейдут в статус **Без исполнителя**, если
не выбрать получателя.

### Как настроить двухфакторную аутентификацию?

**Настройки → Безопасность → 2FA**. Можно сделать обязательной
для администраторов или опциональной для всех.

## <a id="интеграции-и-api">Интеграции и API</a>

### Как получить API-токен?

**Профиль → API-токены → Создать токен**. Укажите название,
срок действия и права. Скопируйте токен — он отобразится **один раз**.

### Как подключить Slack?

**Настройки → Интеграции → Slack → Подключить**. Авторизуйтесь
в Slack, выберите канал для уведомлений.

### Как настроить webhook?

**Настройки → Интеграции → Webhooks → Добавить**. Укажите URL,
события и секретный ключ. Нажмите **Проверить** — система отправит
тестовый запрос.

### Где документация по API?

Раздел [API](api/reference.md). Там интерактивная документация
на основе OpenAPI-спецификации.

## <a id="ошибки">Ошибки</a>

### Ошибка «Access denied»

Проверьте роль пользователя. Для выполнения операции нужны права
**Менеджер** или **Администратор**. Роли назначает администратор
в разделе **Пользователи**.

### Ошибка «Database connection timeout»

Увеличьте таймаут подключения к базе в `config.yml`:

```yaml
database:
  timeout: 30
```

После изменения перезапустите контейнеры:

```bash
docker compose restart
```

### Ошибка «File too large»

Максимальный размер вложения — **25 МБ**. Если файл больше:

- сожмите его;
- загрузите в облако и дайте ссылку в комментарии;
- разбейте на несколько файлов.

### Ошибка «Session expired»

Сессия завершилась из-за неактивности. Войдите заново.
Таймаут настраивается администратором в **Настройки → Безопасность**.

### Ошибка «SMTP authentication failed»

Проверьте логин и пароль. Для Gmail и Яндекс.Почты обычный пароль
не подойдёт — нужен **пароль приложения**.

## <a id="производительность">Производительность</a>

### Канбан-доска тормозит при большом количестве задач

Если задач больше 30 в колонке — включите фильтр по исполнителю
или тегу. Доска станет быстрее и читаемее.

Если тормозит вся система — проверьте:

1. Нагрузку на сервер: `docker stats`.
2. Размер базы данных.
3. Количество активных пользователей.

### Поиск работает медленно

Поиск индексирует задачи, комментарии и вложения. Если данных много,
индексация может занимать время. Проверьте статус индекса
в **Администрирование → Обслуживание**.

### Экспорт большого отчёта зависает

Если строк больше 1000, экспорт выполняется в фоне. Дождитесь письма
со ссылкой. Не закрывайте страницу — это не поможет.
