## **Как читать этот документ**

Версии ведутся по [Semantic Versioning](https://semver.org/lang/ru/):

| Тип | Когда использовать | Пример |
| --- | --- | --- |
| **Major** | Несовместимые изменения API или интерфейса | `1.0.0` → `2.0.0` |
| **Minor** | Новая функциональность, обратно совместимая | `1.0.0` → `1.1.0` |
| **Patch** | Исправления без новой функциональности | `1.0.0` → `1.0.1` |

## **Типы изменений:**

- **Новое** — новая функциональность.
- **Улучшения** — изменения существующей функциональности.
- **Исправления** — устранённые ошибки.
- **Устарело** — функциональность, которую планируется удалить.
- **Удалено** — удалённая функциональность.
- **Безопасность** — исправления уязвимостей.

## **Связь версий с документацией**

Версия документа в шапке PDF и в колонтитулах **автоматически берётся
из первой (самой свежей) записи этого файла**. При добавлении новой версии:

1. Обновляется шапка PDF.
2. Обновляется таблица «Изменения в документе».
3. Обновляются колонтитулы на всех страницах.

Это принцип single source of truth: одна запись — одно обновление
во всех документах.

## 3.3.0 — октябрь 2026

Автор: Кудряшова Т.В.

Дата: 15.10.2026

Описание: Фильтры задач по тегам, шаблоны проектов, экспорт в CSV.

### Новое

- Фильтры задач по тегам и комбинации фильтров.

- Экспорт отчётов в CSV для загрузки в BI-системы.

- Ускорена загрузка списка задач на 25 %.
- Переработана страница «Настройки»: разделы сгруппированы по смыслу.
- Улучшена подсветка синтаксиса в комментариях к задачам.

### Исправления

- Исправлена ошибка с дублированием задач при копировании проекта.
- Устранён сбой при фильтрации более 5000 задач.
- Исправлено отображение дат в часовом поясе UTC+7.
