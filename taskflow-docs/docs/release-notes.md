## 3.2.0 — сентябрь 2026

Автор: Кудряшова Т.В.
Дата: 11.09.2026
Описание: Массовые операции с задачами, экспорт отчётов в PDF, тёмная тема.

### Новое

- Массовые операции с задачами: назначение исполнителя, смена приоритета,

- Ускорена загрузка канбан-доски на 40 %.

### Исправления

- Исправлена ошибка с часовыми поясами в сроках задач.
- Устранён сбой при экспорте более 1000 задач в Excel.
