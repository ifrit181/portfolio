# TaskFlow

**TaskFlow** — система управления задачами и проектами для команд любого размера.
Помогает планировать работу, распределять задачи, отслеживать прогресс
и анализировать загрузку.

## <a id="что-это-за-сайт">Что это за сайт</a>

Это **демонстрационное портфолио** технического писателя. Здесь показано,
как может выглядеть документация продукта, собранная по принципам **Docs as Code**:

- контент в Markdown, хранится в Git;
- сборка сайта через MkDocs Material;
- автоматический деплой на GitHub Pages через CI/CD;
- переиспользование контента через сниппеты;
- версионность документации, связанная с Release notes;
- генерация PDF и `.docx` по шаблонам.

## <a id="технологии">Технологии, использованные в портфолио</a>

- **MkDocs** + **Material for MkDocs** — генерация сайта
- **Markdown**, **YAML** — контент и конфигурация
- **Git**, **GitHub** — версионирование, ветки, MR
- **GitHub Actions** — CI/CD, автодеплой, валидация
- **`pymdownx.snippets`** — переиспользование контента
- **Swagger UI** — интерактивная документация API
- **Python** (`python-docx`, `docxtpl`) — генерация `.docx` по шаблону
- **LibreOffice** — конвертация `.docx` → PDF
