# TaskFlow

**TaskFlow** — система управления задачами и проектами для команд любого размера.
Помогает планировать работу, распределять задачи, отслеживать прогресс
и анализировать загрузку.

## Возможности

- Канбан-доски и списки задач
- Проекты, спринты и вехи
- Назначение исполнителей и сроков
- Комментарии, вложения, чек-листы
- Отчёты по загрузке и срокам
- Интеграция с внешними системами через API
- Разграничение доступа по ролям
