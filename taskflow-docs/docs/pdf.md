# Скачать в PDF

Любую страницу документации можно сохранить в PDF: с титульным листом,
оглавлением и номерами страниц.

## <a id="как-скачать-страницу">Как скачать страницу</a>

1. Откройте нужную страницу, например [Интерфейс](getting-started/interface.md).
2. В нижнем правом углу появится круглая кнопка с иконкой документа — **Скачать в PDF**.
3. Нажмите кнопку; файл сохранится в папке загрузок, например `interface.pdf`.

Кнопка видна только на тех страницах, где PDF доступен.

## <a id="что-внутри-pdf">Что внутри PDF</a>

- **Титульный лист** — название документа и надпись «Руководство пользователя».
- **Оглавление** — разделы и подразделы с номерами страниц.
- **Содержание раздела** — предупреждения и вставки уже раскрыты в тексте.
- **Колонтитулы** — название документа и номер страницы.

Номер страницы в оглавлении совпадает с фактической страницей раздела,
поэтому по PDF удобно ориентироваться при чтении и в распечатанном виде.

## <a id="версия-и-дата">Версия и дата</a>

На титульном листе указана версия документа. Она совпадает с последней
версией в [Release notes](release-notes.md) — при выходе новой версии она
подставляется автоматически.
Дата в таблице изменений обновляется при каждой пересборке документации
и отражает момент последней публикации.

## <a id="особенности">Особенности</a>

- PDF формируется автоматически при публикации документации и всегда
  соответствует актуальным исходникам.
- Разделы с вложенными заголовками получают полное оглавление с номерами.
- Вставки и предупреждения включены в текст (гиперссылки сохраняются,
  но не активны в печатной версии).
- Для отдельных записей [блога](blog/index.md) PDF не генерируется.
