## <a id="авторизация">Авторизация</a>

Все запросы требуют заголовок `Authorization` с токеном:

```http
GET /api/v1/projects HTTP/1.1
Host: taskflow.example.com
Authorization: Bearer <токен>
```

Токен создаётся в разделе **Профиль** → **API-токены**.

## <a id="основные-методы">Основные методы</a>

### Получить список проектов

```
GET /api/v1/projects
```

Ответ:

```json
{
  "items": [
    {
      "id": "prj_001",
      "name": "Внедрение TaskFlow",
      "status": "active",
      "created_at": "2026-01-15T10:00:00Z"
    }
  ],
  "total": 1
}
```

### Создать задачу

```
POST /api/v1/projects/{project_id}/tasks
Content-Type: application/json
```

Тело запроса:

```json
{
  "title": "Подготовить документацию",
  "assignee_id": "usr_042",
  "due_date": "2026-10-01",
  "priority": "high"
}
```

### Обновить задачу

```
PATCH /api/v1/tasks/{task_id}
Content-Type: application/json
```

Тело запроса:

```json
{
  "status": "in_progress"
}
```

## <a id="коды-ответов">Коды ответов</a>

| Код | Значение |
| --- | --- |
| 200 | Успех |
| 201 | Создано |
| 400 | Ошибка в запросе |
| 401 | Не авторизован |
| 403 | Нет прав |
| 404 | Не найдено |
| 429 | Слишком много запросов |
| 500 | Ошибка сервера |

## <a id="лимиты">Лимиты</a>

- 1000 запросов в час на токен.
- Размер тела запроса — до 1 МБ.
- Пагинация — по 50 элементов, параметры `offset` и `limit`.
