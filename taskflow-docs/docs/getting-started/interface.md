## <a id="боковое-меню">Боковое меню</a>

Боковое меню содержит разделы:

- **Проекты** — список проектов и канбан-доски
- **Задачи** — все задачи, назначенные вам
- **Отчёты** — аналитика по загрузке и срокам
- **Администрирование** — раздел доступен только с ролью **Администратор**

## <a id="верхняя-панель">Верхняя панель</a>

В верхней панели расположены:

- **Поиск** — глобальный поиск по задачам, проектам и комментариям
- **Уведомления** — обновления по задачам, где вы участвуете
- **Профиль** — настройки аккаунта, API-токены, выход

## <a id="канбан-доска">Канбан-доска</a>

Канбан-доска показывает задачи по колонкам в соответствии со статусами.
Перетаскивайте карточки между колонками, чтобы менять статус задачи.
Фильтруйте доску по исполнителю, тегу или приоритету.

## <a id="темная-тема">Тёмная тема</a>

Используйте переключатель в верхней панели, чтобы включить тёмную тему.
Выбор сохраняется между сессиями.
