## <a id="верхняя-панель">1. Верхняя панель</a>

Расположена вверху экрана. Содержит:

| Элемент | Назначение |
| --- | --- |
| Логотип | Возврат на дашборд |
| Поиск | Глобальный поиск по задачам, проектам, людям |
| Создать | Быстрое создание задачи, проекта, встречи |
| Уведомления | Список непрочитанных событий |
| Профиль | Настройки, выход, переключение темы |

!!! tip "Горячая клавиша поиска"
    Нажмите `/` в любом месте системы — курсор переместится в строку поиска.

## <a id="левое-меню">2. Левое меню</a>

Основная навигация. Сворачивается кнопкой в правом верхнем углу меню.

### Основные разделы

| Раздел | Что внутри |
| --- | --- |
| **Дашборд** | Сводка по задачам и проектам |
| **Мои задачи** | Задачи, назначенные на вас |
| **Проекты** | Список всех доступных проектов |
| **Отчёты** | Аналитика и экспорт |
| **Команда** | Список участников организации |
| **Администрирование** | Доступно только администраторам |

### Контекстное меню

Внутри проекта появляются дополнительные пункты:

- **Доска** — канбан-представление
- **Список** — табличное представление
- **Спринты** — планирование итераций
- **Вехи** — ключевые события
- **Участники** — роли и права
- **Настройки** — параметры проекта

## <a id="рабочая-область">3. Рабочая область</a>

Занимает центральную часть экрана. Содержимое зависит от выбранного раздела.

### Дашборд

Виджеты:

- **Мои задачи на сегодня** — список с дедлайнами.
- **Активность команды** — последние действия коллег.
- **График загрузки** — распределение задач по дням.
- **Ближайшие вехи** — что скоро наступит.

Виджеты можно перетаскивать и скрывать через кнопку **Настроить**.

### <a id="канбан-доска">Канбан-доска</a>

Колонки соответствуют статусам задач:

| Колонка | Значение |
| --- | --- |
| Новая | Задача создана, не взята в работу |
| В работе | Исполнитель приступил |
| На проверке | Ожидает ревью |
| Готова | Завершена |

Карточки перетаскиваются мышью между колонками. Статус меняется автоматически.

### Список задач

Табличное представление с сортировкой и фильтрацией:

- сортировка по столбцу — клик по заголовку;
- фильтр — кнопка **Фильтр** над таблицей;
- группировка — по исполнителю, приоритету, сроку.

## <a id="нижняя-панель">4. Нижняя панель</a>

Тонкая полоса внизу экрана. Показывает:

- статус подключения (онлайн/офлайн);
- количество активных фоновых операций;
- версию системы;
- ссылку на поддержку.

## <a id="настройка-интерфейса">Настройка интерфейса</a>

### Смена темы

Доступны три режима:

1. **Светлая** — для работы днём.
2. **Тёмная** — для работы вечером.
3. **Системная** — автоматически по настройкам ОС.

Переключение: **Профиль → Тема**.

### Плотность

В разделе **Профиль → Интерфейс** можно выбрать:

- **Комфортная** — увеличенные отступы.
- **Компактная** — больше информации на экране.

### Язык

Система поддерживает русский и английский. Переключение:
**Профиль → Язык**.

## <a id="горячие-клавиши">Горячие клавиши</a>

| Клавиша | Действие |
| --- | --- |
| `/` | Поиск |
| `N` | Новая задача |
| `P` | Новый проект |
| `G` затем `D` | Перейти на дашборд |
| `G` затем `T` | Перейти к моим задачам |
| `?` | Список всех горячих клавиш |
| `Esc` | Закрыть диалог |

!!! note "Полный список"
    Нажмите `?` в любом месте системы — откроется окно со всеми
    горячими клавишами.
