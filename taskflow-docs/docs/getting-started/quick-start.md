## <a id="вход-в-систему">1. Вход в систему</a>

Откройте адрес вашего сервера и войдите под своей учётной записью.
Если учётной записи ещё нет — обратитесь к администратору.

## <a id="создание-проекта">2. Создание проекта</a>

1. В боковом меню нажмите **Проекты** → **Создать проект**.
2. Укажите название, например, «Запуск сайта».
3. Нажмите **Сохранить**.

## <a id="создание-задачи">3. Создание задачи</a>

1. Откройте созданный проект.
2. Нажмите **Создать задачу**.
3. Заполните поля: **Название**, **Описание**, при необходимости
   **Исполнитель** и **Срок**.
4. Нажмите **Сохранить**.

## <a id="перемещение-по-канбан-доске">4. Перемещение по канбан-доске</a>

Откройте вкладку **Доска**. Перетащите карточку задачи из колонки
**Новая** в колонку **В работе**.
