Это руководство поможет создать первый проект и задачу за 10 минут.
Предполагается, что TaskFlow уже установлен и вы вошли под администратором.

## <a id="вход-в-систему">1. Вход в систему</a>

Откройте адрес вашего сервера и войдите под своей учётной записью.
Если учётной записи ещё нет — обратитесь к администратору.

## <a id="создание-проекта">2. Создание проекта</a>

Проект — это контейнер для задач, объединённых общей целью.

1. На дашборде нажмите **Создать проект**.
2. Заполните поля:

   | Поле | Значение |
   | --- | --- |
   | Название | `Внедрение TaskFlow` |
   | Описание | `Пилотный проект для знакомства с системой` |
   | Тип | `Канбан` |
   | Участники | Добавьте себя |

3. Нажмите **Создать**.

Система откроет страницу проекта с пустой канбан-доской.

## <a id="создание-задачи">3. Создание задачи</a>

1. В колонке **Новая** нажмите **+**.
2. Введите название: `Изучить интерфейс`.
3. Нажмите **Enter**.

Задача появится в колонке. Карточка отображает название, исполнителя
и приоритет.

!!! tip "Горячие клавиши"
    - `N` — новая задача в текущей колонке
    - `E` — редактировать выбранную задачу
    - `D` — отметить как выполненную

## <a id="настройка-задачи">4. Настройка задачи</a>

Кликните на карточку, чтобы открыть детали. Заполните:

- **Описание** — что нужно сделать.
- **Исполнитель** — выберите себя из списка.
- **Срок** — укажите дату.
- **Приоритет** — `Средний`.
- **Теги** — добавьте `онбординг`.

Сохраните — изменения применятся автоматически.

## <a id="перемещение-по-канбан-доске">5. Перемещение по канбан-доске</a>

Перетащите карточку из колонки **Новая** в колонку **В работе**.
Статус задачи изменится, и она появится в отчётах.

## <a id="создание-второй-задачи">6. Создание второй задачи</a>

Добавьте ещё одну задачу в колонку **Новая**:

> Настроить интеграцию со Slack

Назначьте её себе, установите срок через неделю.

## <a id="просмотр-отчётов">7. Просмотр отчётов</a>

1. Откройте раздел **Отчёты** в левом меню.
2. Выберите отчёт **Задачи по статусам**.
3. Убедитесь, что обе задачи отображаются: одна в работе, одна новая.

## <a id="приглашение-участника">8. Приглашение участника</a>

1. Откройте проект → **Участники** → **Пригласить**.
2. Введите email коллеги.
3. Выберите роль `Сотрудник`.
4. Нажмите **Отправить приглашение**.

Коллега получит письмо со ссылкой на проект.

## <a id="что-вы-сделали">Что вы сделали</a>

За 10 минут вы:

- создали проект;
- добавили две задачи;
- настроили их параметры;
- изменили статус через канбан-доску;
- посмотрели отчёт;
- пригласили участника.
