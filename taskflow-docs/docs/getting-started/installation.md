# Установка

Установка TaskFlow занимает около 15 минут. Система разворачивается в Docker-контейнерах,
поэтому отдельно устанавливать базу данных и зависимости не требуется.

## <a id="требования">Требования</a>

Перед установкой убедитесь, что сервер соответствует минимальным требованиям.

| Компонент | Минимум | Рекомендуется |
| --- | --- | --- |
| ОС | Ubuntu 20.04 LTS | Ubuntu 22.04 LTS |
| CPU | 2 ядра | 4 ядра |
| RAM | 4 ГБ | 8 ГБ |
| Диск | 20 ГБ SSD | 50 ГБ SSD |
| Docker | 20.10+ | 24.0+ |
| Docker Compose | 2.0+ | 2.20+ |

!!! note "Проверка версий"
    Убедитесь, что Docker и Docker Compose установлены:

    ```bash
    docker --version
    docker compose version
    ```

    Если команды не найдены — установите Docker по
    [официальной инструкции](https://docs.docker.com/engine/install/ubuntu/).

## <a id="порядок-установки">Порядок установки</a>

### 1. Подготовка сервера

Обновите пакеты и установите утилиты:

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y git curl
```

### 2. Загрузка дистрибутива

Склонируйте репозиторий с конфигурацией:

```bash
git clone https://github.com/taskflow/taskflow-deploy.git
cd taskflow-deploy
```

### 3. Настройка переменных окружения

Скопируйте шаблон конфигурации и отредактируйте его:

```bash
cp .env.example .env
nano .env
```

Укажите обязательные параметры:

```ini
# Адрес, по которому будет доступна система
TASKFLOW_HOST=https://taskflow.company.com

# Учётные данные администратора
ADMIN_EMAIL=admin@company.com
ADMIN_PASSWORD=<надёжный-пароль>

# Параметры базы данных
DB_PASSWORD=<пароль-базы-данных>

# Секретный ключ для подписи токенов
SECRET_KEY=<сгенерируйте-командой-openssl-rand-hex-32>
```

!!! warning "Безопасность"
    Не используйте пароли по умолчанию. Сгенерируйте `SECRET_KEY` командой:

    ```bash
    openssl rand -hex 32
    ```

### 4. Запуск контейнеров

Запустите систему:

```bash
docker compose up -d
```

Docker скачает образы и запустит пять контейнеров:

| Контейнер | Назначение |
| --- | --- |
| `taskflow-app` | Веб-приложение |
| `taskflow-worker` | Фоновая обработка задач |
| `taskflow-db` | База данных PostgreSQL |
| `taskflow-cache` | Кэш Redis |
| `taskflow-nginx` | Веб-сервер и reverse proxy |

Проверьте, что все контейнеры запустились:

```bash
docker compose ps
```

Все контейнеры должны быть в статусе `running` или `healthy`.

### 5. Первичная настройка

Откройте веб-интерфейс по адресу из переменной `TASKFLOW_HOST`.
При первом запуске система предложит создать учётную запись администратора:

1. Введите email и пароль.
2. Укажите название организации.
3. Нажмите **Создать**.

После создания администратора система перенаправит на дашборд.

## <a id="проверка-установки">Проверка установки</a>

Убедитесь, что система работает корректно:

- [ ] Веб-интерфейс открывается по адресу `TASKFLOW_HOST`.
- [ ] Вход под администратором выполняется успешно.
- [ ] На дашборде отображаются виджеты (пустые — это нормально).
- [ ] В разделе **Администрирование → Настройки** доступны параметры.
- [ ] В логах нет ошибок: `docker compose logs --tail=50`.

## <a id="обновление">Обновление</a>

Для обновления до новой версии:

```bash
cd taskflow-deploy
git pull
docker compose pull
docker compose up -d
```

!!! warning "Резервная копия перед обновлением"
    Перед обновлением создайте резервную копию базы данных:

    ```bash
    docker compose exec taskflow-db pg_dump -U taskflow taskflow > backup_$(date +%F).sql
    ```

## <a id="удаление">Удаление</a>

Чтобы полностью удалить систему:

```bash
docker compose down -v
```

Флаг `-v` удаляет тома с данными. Без него данные сохранятся.
