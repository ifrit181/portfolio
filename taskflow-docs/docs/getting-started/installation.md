| ОС | Ubuntu 20.04 | Ubuntu 22.04 |

| RAM | 4 ГБ | 8 ГБ |
| Диск | 20 ГБ SSD | 50 ГБ SSD |

## <a id="порядок-установки">Порядок установки</a>

### 1. Подготовка сервера

Обновите пакеты и установите зависимости:

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y docker.io docker-compose
```

### 2. Развёртывание

Склонируйте репозиторий и запустите контейнеры:

```bash
git clone https://github.com/taskflow/taskflow-deploy.git
cd taskflow-deploy
docker-compose up -d
```

### 3. Первичная настройка

Откройте веб-интерфейс по адресу `http://<адрес-сервера>:8080`
и создайте учётную запись администратора.

## <a id="проверка-установки">Проверка установки</a>

1. Откройте `http://<адрес-сервера>:8080`.
2. Войдите под учётной записью администратора.
3. Убедитесь, что открылся список проектов.
