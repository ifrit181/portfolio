# Реквизиты ГОСТ-оформления: front-matter ключи

Справочник ключей `gost_*` для front matter markdown-файлов генератора PDF по ГОСТ
(`gost_pdf/generate_pdf_gost.py`). Раскладка полей титульного листа — ГОСТ 19.104-78,
п. 3.1 (см. `matrix.md`, § 4.1); все значения по умолчанию — **пустые**.

Полный пример front matter со всеми ключами и списком обязательных разделов
для каждого вида документа — `front-matter.example.yaml` (комментарии в файле).

## Пример

```yaml
---
gost_doc_type: rukovodstvo-polzovatelya
gost_product_name: СИСТЕМА УПРАВЛЕНИЯ ЗАДАЧАМИ
gost_oboznachenie: ТС 12345.678-2026
gost_litera: Б
gost_lu_oboznachenie: ТС 12345.678-2026-ЛУ
gost_ministerstvo: Министерство цифрового развития
gost_otmetka_ucheta: Инв. № 12345, Экз. № 1
gost_stroka_izmenenij: Версия документа – 1.2
gost_left_margin_30: true
gost_annotation: |
  Назначение документа и краткое содержание.

  Область применения и читатели.
---
```

## Ключи

| Ключ | Поле титула / назначение | По умолчанию |
|---|---|---|
| `gost_product_name` | поле 3 — полное наименование программы/изделия **прописными** | первый H1 markdown-файла |
| `gost_doc_type` | вид документа — вторая строка под наименованием (поле 3); определяет обязательные разделы и обязательность аннотации | `rukovodstvo-polzovatelya` |
| `gost_oboznachenie` | поле 4 — обозначение документа (ГОСТ 19.103-77); продублировано в шапке контентных страниц (левый верхний угол, ГОСТ 19.106-78, п. 2.1.2) | пусто |
| `gost_litera` | поле 10 — литера документа (строка «… г. · Литера X») | пусто |
| `gost_otmetka_ucheta` | поле 8 — отметка об учёте и хранении (ГОСТ 19.601-78, п. 2.6) | пусто |
| `gost_stroka_izmenenij` | поле 9 — строка изменений (ГОСТ 19.604-78); также выводится в правом нижнем поле контентных страниц | пусто |
| `gost_lu_oboznachenie` | надпись «УТВЕРЖДЕНО / обозначение ЛУ» в левом верхнем углу (ГОСТ 19.104-78, п. 3.2) | пусто — выводится только «УТВЕРЖДЕНО» |
| `gost_ministerstvo` | поле 1 — наименование министерства/ведомства | пусто |
| `gost_left_margin_30` | левое поле 30 мм вместо 20 мм — для документов со сроком хранения > 10 лет (ГОСТ Р 7.0.97-2016, п. 6.1) | `false` |
| `gost_author` | автор документа — метаданные PDF (`/Author`) | автор последней версии из `docs/release-notes.md` |
| `gost_annotation` | информационная часть: страница «АННОТАЦИЯ» перед содержанием (ГОСТ 19.105-78, п. 1.6). Блоки разделяются пустой строкой, одиночные переводы строк внутри блока склеиваются | пусто |

Автозаполняемые поля титула: **поле 5** «Листов N» — по результату первого прохода
(при одном листе не выводится), **поле 7** — текущий год.

Обязательность `gost_annotation` и состав обязательных разделов зависят от
`gost_doc_type`; отсутствие генератор отмечает предупреждениями при сборке.

## Виды документов (`gost_doc_type`)

Ключи и русские алиасы (регистр не важен) — `doc_types.py`:

| Ключ | Вид документа | Код |
|---|---|---|
| `tz` | Техническое задание | 01 |
| `spetsifikatsiya` | Спецификация | 00 |
| `programma-ispytanij` | Программа и методика испытаний | 51 |
| `tekst-programmy` | Текст программы | 12 |
| `opisanie-programmy` | Описание программы | 13 |
| `poyasnitelnaya-zapiska` | Пояснительная записка | 81 |
| `opisanie-primeneniya` | Описание применения | 31 |
| `rukovodstvo-sistemnogo-programmista` | Руководство системного программиста | 32 |
| `rukovodstvo-programmista` | Руководство программиста | 33 |
| `rukovodstvo-operatora` | Руководство оператора | 34 |
| `opisanie-yazyka` | Описание языка | 35 |
| `vedomost-ekspluatatsionnyh-dokumentov` | Ведомость эксплуатационных документов | 20 |
| `rukovodstvo-polzovatelya` | Руководство пользователя | И3 |
| `opisanie-po` | Описание программного обеспечения | ПА |

Обязательные разделы (сверяются по заголовкам уровней 1–2) и признак
информационной части (`info_part`) — в `doc_types.py`; стандарт содержания
указан в поле `content_standard` (например, ГОСТ Р 59795-2021, п. 6.4 для
руководства пользователя).
