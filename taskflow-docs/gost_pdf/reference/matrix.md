# Матрица «вид документа → ГОСТ»

Источник — файлы папки `taskflow-docs/gost_pdf/gost/`. Матрица связывает:
вид (тип) документа → стандарт(ы), задающие **содержание** → стандарты, задающие
**оформление** → пункты, по которым построен `gost_styles.py` / `titlepage.py`.

---

## 3. Порядок частей документа (ГОСТ 19.105-78, п. 1.6; ГОСТ 19.106-78, п. 1.6)

1. Титульная часть:
   - лист утверждения (ЛУ) — **не входит** в количество листов, при необходимости;
   - титульный лист — первый лист документа.
2. Информационная часть:
   - аннотация — отдельная нумерованная страница с заголовком «АННОТАЦИЯ»,
     не нумеруется как раздел (ГОСТ 19.106-78, п. 2.1.3);
   - содержание — отдельная страница, заголовок «СОДЕРЖАНИЕ», входит в число
     страниц (ГОСТ 19.106-78, п. 2.1.4).
3. Основная часть: текст с рисунками и таблицами.
4. Приложения (при наличии), затем перечни (терминов, сокращений, рисунков,
   таблиц, предметный указатель) — по необходимости.
5. Часть регистрации изменений: записи о каждом изменении — по ГОСТ 19.603-78
   (ГОСТ 19.105-78, п. 5.1); форма листа регистрации изменений — ГОСТ 19.604-78,
   форма 1; извещения о внесении изменений — ГОСТ 19.603-78, прил. 2.

Обязательность информационной части по видам — см. табл. в п. 1.2.

## 4. Титульный лист, ЛУ, обозначения и учёт (ГОСТ 19.104-78, 19.103-77, 19.601-78)

### 4.1. Титульный лист

Титульный лист заполняется по форме листа утверждения; заполняются поля
(п. 3.1), значения по умолчанию — **пустые**:

| Поле | Содержание | Источник по умолчанию |
|---|---|---|
| 1 | наименование министерства/ведомства | пусто |
| 2 | подписи (на титуле не заполняется) | не заполняется |
| 3 | полное наименование программы/изделия прописными, наименование и вид документа | автозаполнение: первый H1 MD + вид документа из `gost_doc_type` |
| 4 | обозначение документа (ГОСТ 19.103-77) и вид носителя | пусто (`gost_oboznachenie`) |
| 5 | объём документа (листов) | автозаполнение после первого прохода |
| 6 | подписи (на титуле не заполняется) | не заполняется |
| 7 | год издания (утверждения) | автозаполнение: текущий год |
| 8 | отметка об учёте и хранении (ГОСТ 19.601-78) | пусто (`gost_otmetka_ucheta`) |
| 9 | строка изменений (ГОСТ 19.604-78) | пусто (`gost_stroka_izmenenij`) |
| 10 | литера документа | пусто (`gost_litera`) |

Дополнительно на титуле (п. 3.2): надпись **«УТВЕРЖДЕНО / обозначение ЛУ»** в левом
верхнем углу — обязательна; обозначение берётся из `gost_lu_oboznachenie` (по
умолчанию пусто — выводится строка «УТВЕРЖДЕНО» без второй строки). Пример заполнения —
справочное приложение 3 ГОСТ 19.104-78.

### 4.2. Лист утверждения (ЛУ, ГОСТ 19.104-78, п. 2.1–2.5)

- ЛУ выпускается на **каждый** программный документ, листы А4, **не входит** в общее
  количество листов документа (ГОСТ 19.106-78, п. 1.6); обозначение ЛУ = обозначение
  документа + «-ЛУ» (п. 2.2, см. пример в § 4.3).
- Поля ЛУ (п. 2.5): 1 — министерство/ведомство; 2 — подписи: слева — согласовавшие от
  организации заказчика, справа — утвердившие от организации разработчика; 3 — полное
  наименование программы прописными + наименование и вид документа; 4 — обозначение и вид
  носителя; 5 — «Листов N» (для одного листа не заполняют); 6 — руководитель организации,
  подразделения, руководитель разработки, исполнители, нормоконтролёр; 7 — год;
  8 — отметка об учёте; 9 — строка изменений; 10 — литера. Пример заполнения — приложение 2.
- Статус генератора: **ЛУ не строится** — только титульный лист; ЛУ при необходимости
  оформляется вручную и прикладывается отдельным листом (не входит в счётчик листов).

### 4.3. Примеры обозначений (ГОСТ 19.103-77, ГОСТ 19.104-78, прил. 2–3)

| Пример | Расшифровка |
|---|---|
| `А.В.00001-01 33 01-1` | А — код страны, В — код организации-разработчика, `00001` — рег. №, `01` — № редакции (издания программы), `33` — код вида «Руководство программиста» (табл. 4 ГОСТ 19.101-77), `01` — № документа вида, `-1` — № части |
| `А.В.00001-01 33 01-1-ЛУ` | то же + «-ЛУ» — обозначение листа утверждения (ГОСТ 19.104-78, п. 2.2) |
| `А.В.00001-01` | обозначение без группы вида документа — номер издания программы; структура обозначения программы и её спецификации (ГОСТ 19.103-77, п. 3); номер редакции спецификации и ВЭД совпадает с номером издания программы (п. 9) |

Разделители групп по ГОСТ 19.103-77, п. 2: точка — после кода страны/организации,
пробел — после номера редакции и кода вида, дефис — после рег. номера и номера документа.
Если документ состоит из одной части — дефис и номер части не указывают (п. 8, примечание).

### 4.4. Учёт и хранение (ГОСТ 19.601-78)

- Учёту и хранению в ОТД/БТД подлежат подлинники, дубликаты и копии **всех** программных
  документов, **кроме ТЗ** (п. 1.1); условия — по ГОСТ 2.501-68 (п. 1.2).
- Отметка учёта («ИНВ. № …, ЭКЗ. № …», «КОНТРОЛЬНЫЙ ЭКЗЕМПЛЯР») — поле 8 титула; штамп
  учёта располагают в левом нижнем углу поля для подшивки листа утверждения или титульного
  листа (п. 2.6). Значение — `gost_otmetka_ucheta` (по умолчанию пусто).
- Конкретные **сроки хранения** стандартами ЕСПД не устанавливаются — определяются
  перечнем (номенклатурой) дел организации; инвентарный номер и карточка учёта — п. 2.7–2.8.
- Для документов со сроком хранения **>10 лет** — левое поле 30 мм (ГОСТ Р 7.0.97-2016,
  п. 6.1; ключ `gost_left_margin_30`).

См. также `reference/РЕКВИЗИТЫ.md`.

## 7. Приоритеты при противоречиях: примеры

Правило приоритета (§ 2): **ГОСТ Р 7.0.97-2016** → **ГОСТ 19.106-78** → **ГОСТ Р 2.105-2019**.

| Вопрос | ГОСТ 19.106-78 | ГОСТ Р 2.105-2019 | ГОСТ Р 7.0.97-2016 | Решение в генераторе |
|---|---|---|---|---|
| Абзацный отступ | п. 2.1.6: каждый структурный элемент начинается с абзацного отступа, размер не задан | п. 5.1.4: пять знаков гарнитуры (12,5–17 мм) | п. 3.4: 1,25 см | 1,25 см (в диапазоне Р 2.105), одинаковый по всему тексту (`gost_styles.py`) |
| Выравнивание заголовка раздела | п. 2.1.7: прописными, симметрично по центру; подразделы — с абзаца, строчными | п. 6.6.2: прописные, полужирные, разделы — увеличенным кеглем; выравнивание не нормирует | п. 3.4: «с абзацного отступа **или** центрируются» | ЕСПД: разделы — по центру, подразделы — с абзаца (19.106); ЕСКД/Р 7.0.97 — допускает центр |
| Расстояние перед заголовком | п. 2.1.8: машинный способ — не менее 3 высот шрифта (машинописный — 2 интервала) | п. 6.6.3: не менее 2 высот шрифта | — | не менее 3 высот (`space_after` заголовка = 3× кегль) |
