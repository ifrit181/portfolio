# Генерация DOCX из markdown-файла

Скрипт `generate_single.py` преобразует один markdown-файл в Word-документ (.docx) с титульной страницей, оглавлением и нумерацией разделов.

## Зависимости

```bash
pip install python-docx pyyaml
```

## Формат вызова

```bash
python3 generate_single.py <md_file> [--output-dir <dir>] [--product-name <name>]
```

| Аргумент | Описание |
|---|---|
| `md_file` | Путь к markdown-файлу (абсолютный или относительный) |
| `--output-dir` | Каталог для выходного DOCX. По умолчанию — `output/` рядом с MD-файлом |
| `--product-name` | Название продукта для титульной страницы. По умолчанию — текст первого H1 из MD |

## Примеры запуска

```bash
# Базовое использование — название берётся из первого H1
python3 generate_single.py "Как настроить рейсы ПДМ на бортовом ПО.md"

# Указать каталог вывода
python3 generate_single.py "Как настроить рейсы ПДМ на бортовом ПО.md" --output-dir ./build

# Задать название продукта вручную
python3 generate_single.py my_guide.md --product-name "СигМА"

# Все параметры вместе
python3 generate_single.py "Как настроить рейсы ПДМ на бортовом ПО.md" \
    --output-dir ./build \
    --product-name "СигМА"
```

## Что генерируется

1. **Титульная страница** — по шаблону `primer.docx` из директории `sigma/`
2. **Изменения в документе** — таблица версий и предупреждение о конфиденциальности
3. **Содержание** — автообновляемое Word-поле (обновляется при открытии в Word: ПКМ → Обновить поле)
4. **Основное содержимое** — markdown конвертируется в стилизованные параграфы, таблицы, списки, рисунки
5. **Колонтитуры** — название продукта в шапке, копирайт в подвале

## Нумерация разделов

Заголовки MD-файла автоматически нумеруются по уровням вложенности:

```
# Раздел          → 1 Раздел
## Подраздел      → 1.1 Подраздел
### Подподраздел  → 1.1.1 Подподраздел
```

Страницы автоматически разбиваются между разделами верхних уровней (1 и 1.1).
